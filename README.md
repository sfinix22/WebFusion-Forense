# WebFusion Forense

Proyecto Android en desarrollo. Busco colaboradores con experiencia en informática forense móvil, seguridad de Android y recuperación de datos.

## Objetivo

Investigar la viabilidad de recuperar archivos de un Samsung Galaxy S9 con Android 10, bloqueado por patrón, conservando los datos originales.

El equipo no tiene depuración USB habilitada ni autorización ADB previa. Falta confirmar el modelo exacto, firmware y parche de seguridad para evaluar compatibilidad.

Las pruebas se realizarán en dispositivos propios o con autorización y equipos de laboratorio.

## Estado actual

El código fuente de WebFusion 0.4.5 está disponible en el ZIP de este repositorio.

Actualmente permite analizar archivos seleccionados, calcular SHA-256, consultar metadatos de fotos y generar informes.

Esta versión todavía no desbloquea teléfonos ni extrae o descifra sus datos protegidos.

## Busco ayuda para

* Evaluar posibilidades y limitaciones técnicas del dispositivo.
* Diseñar pruebas reproducibles en equipos de laboratorio.
* Investigar métodos de adquisición compatibles que preserven los datos.
* Revisar el código y proponer mejoras.

Puedes presentar propuestas en Issues, indicando requisitos, compatibilidad, riesgos y resultados comprobados
